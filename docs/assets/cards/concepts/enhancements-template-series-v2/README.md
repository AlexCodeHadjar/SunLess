# SunLess — ещё 10 карт усилений

Каждая карта сохранена отдельным PNG 952 × 1632 пикселя (7:12) на основе предоставленной обложки. Иллюстрация находится в верхнем поле, название — на нижней плашке. Игровые характеристики не добавлены.

| № | ID | Название |
|---:|:---:|---|
| 1 | U01 | Импровизированное оружие |
| 2 | U12 | Эхо Падальщика Карапакса |
| 3 | U16 | Доспехи Звёздного Легиона |
| 4 | U19 | Капля Ихора |
| 5 | U20 | Костяное копьё |
| 6 | U22 | План побега |
| 7 | U25 | Обычный Камень |
| 8 | U28 | Осколок Луны |
| 9 | U34 | Пыльца Кровавого Цветка |
| 10 | U35 | Лоза Кидо |

Названия и признаки сверены с `04 — Усиления и травмы.md` в проекте. U01, U20 и U22 обозначены там как игровые адаптации, U34 и U35 — игровые карты канонических биологических средств. Иллюстрации являются художественными интерпретациями. Точные промпты сохранены в `prompts.md`.
