# SunLess — 10 новых карт усилений

Каждая карта сохранена отдельным PNG 952 × 1632 пикселя (7:12) на основе предоставленной обложки. Иллюстрация находится в верхнем поле, название — на нижней плашке. Характеристики и игровые значки не добавлены.

| № | ID | Название |
|---:|:---:|---|
| 1 | U07 | Лазурный Клинок |
| 2 | U10 | Посох Ветра |
| 3 | U11 | Золотая Верёвка |
| 4 | U23 | Проворный Шип |
| 5 | U24 | Бесконечная Весна |
| 6 | U26 | Цветение Крови |
| 7 | U27 | Тёмное Крыло |
| 8 | U29 | Маска Ткача |
| 9 | U30 | Осколок Рассвета |
| 10 | U33 | Золотой Панцирь |

Названия и признаки предметов сверены с `04 — Усиления и травмы.md` в проекте. «Посох Ветра» — игровое название канонического посоха. «Золотой Панцирь» — игровое название золотого Эхо Гунлауга; это не Воспоминание. Иллюстрации являются художественными интерпретациями описаний.

Точные промпты генерации сохранены в `prompts.md`.
