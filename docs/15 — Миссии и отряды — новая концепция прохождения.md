# 15 — Миссии и отряды: новая концепция прохождения

> Ветка `gameplay/missions`. Черновик концепции v0.1 от 25.09.2026 — по идее владельца и его ответам на вопросы. Заменяет «проверки неделя за неделей» из GDD (docs/10) и Хронику с неделями (docs/14) **только в этой ветке**, пока владелец не решит сливать.

## 1. Суть в трёх строках

Игрок больше не сверяет цифры. Он **читает** живое описание места, по намёкам понимает, что там ждёт, **собирает отряд** из подходящих героев и **отправляет** его. Пока отряд в пути, можно заниматься другими локациями. По прибытии ситуация раскрывается, игрок **решает, что делает отряд** (варианты зависят от состава), дальше этапы, автобой и **отчёт**.

Санни — первый герой первой главы, а не единственный главный герой. Дальше состав растёт, и главное умение игрока — **кого куда послать**.

## 2. Было → стало

| | Сейчас (main) | В ветке `gameplay/missions` |
|---|---|---|
| Герой | Санни всегда исполнитель; его смерть — конец | Санни — первый герой Главы 1, потом много персонажей; **смерть навсегда**, игра идёт, пока есть кого отправить |
| Время | недели: событие появляется через 0–2 нед., переход по карте — 1 неделя, срок главы 18 нед. | **недель нет**; миссия длится **5–15 с** реального времени; темп держит **усталость героев** |
| Событие | 3 варианта с требованиями и процентом шанса | описание + подозрения + разведданные → отряд → запуск → **прибытие** → выбор действия |
| Проверка | игрок видит % и сравнивает характеристики | **прогноз словами**; настоящий расчёт скрыт и идёт **по этапам** |
| Исполнитель | 1 персонаж + до 3 усилений | **отряд**, размер задаёт миссия (1–5 мест), у каждого героя свой кармашек усилений |
| Выбор | 3 одинаковых варианта для всех | **после прибытия**: базовые варианты + особые, которые **открывают теги отряда** |
| Бой | интерактивное «Столкновение» | **автобой с просмотром** (тот же экран, приёмы выбирает сам отряд, можно промотать) |
| Параллельность | одно событие за раз | **несколько отрядов** одновременно, пока герои свободны |
| Провал сюжета | сюжет двигает только успех | сюжетную миссию **можно повторить**; враги помнят прошлую попытку |

## 3. Игровой цикл

```
 Карта главы
   └─ Карта миссии у своей локации (щелчок или герой брошен на карту)
                             └─ Миссия: «Что происходит» · «Что говорят» · Разведданные
                                   └─ Сбор отряда (перетаскиванием) ─► прогноз словами меняется
                                         └─ «Выступить»
                                               └─ Кольцо таймера над картой миссии (5–15 с)
                                                     └─ Кольцо загорается: «Отряд прибыл»
                                                           └─ Окно прибытия: что увидели + варианты действий
                                                                 └─ Этапы (скрытые броски) ─► [автобой]
                                                                       └─ Отчёт: хроника, награды, травмы, потери
                                                                             └─ Герои отдыхают (таймер) · новые миссии и локации
```

Миссия лежит на карте **картой** (сюжетная — крупнее, в золотой рамке; несколько миссий одного места — веером, подпись места под ними). Кольца до отправки нет. Пока кольцо крутится над одной картой, игрок открывает другие и отправляет туда свободных героев.

## 4. Окно миссии — что видит игрок до запуска

Пример — переделанная E03 «Личинки Горного Короля».

**Что происходит.** Караван встал у перевала: одна повозка опрокинута, волы мертвы третий день. Надсмотрщики гонят рабов разгрести завал и забрать мешки с солью. Из-под брезента тянет сладковатой гнилью.

**Что говорят** (намёки — на теги):
- «Мертвецы шевелятся — будто под кожей кто-то ползает» → `Паразит`, `Мёртвое тело`
- «Их много, мелкие, лезут кучей» → `Стая`
- «Бьёшь — а оно мягкое, как тесто» → `Мягкое тело`
- «Вокруг полно обломков: оси, камни, цепи» → поле `Подручные предметы`
- «Ночью мороз — утром они еле ползают» → `Хладнокровная тварь` (подсказка про `Холод`)

**Разведданные:**

| | |
|---|---|
| Угроза | ●●○○○ — «неприятно, но не смертельно» |
| В пути | ~8 с |
| Место отряда | 1–2 героя |
| Вероятные теги врага | `Паразит` · `Стая` · `Мягкое тело` · `???` (ещё 2 скрыты) |
| Место | `Павший караван`: `Мёртвое тело`, `Подручные предметы` |
| Возможные противники | Личинки Горного Короля (сколько — неясно) |

**Прогноз** (меняется, пока собираешь отряд):
> Санни (цепь, `Импровизация`) → **«Хорошие шансы»** · риск для отряда: **«Могут быть раны»**
> *Почему:* ＋ Импровизация с подручными предметами · ＋ Цепь против мягкой плоти · − Стая против одиночки

Причины показываются **только для связей тегов, которые игрок уже открыл** (профиль уже умеет это запоминать). Чисел нет нигде.

## 5. Прогноз словами

| Слово | Скрытая оценка | Цвет |
|---|---|---|
| Безнадёжно | < 15% | тёмно-красный |
| Очень опасно | 15–35% | красный |
| Опасно | 35–50% | оранжевый |
| Неясно | 50–65% | серый |
| Хорошие шансы | 65–85% | зелёный |
| Уверенно | > 85% | золотой |

- Отдельная строка — **риск для отряда**: «без потерь» / «могут быть раны» / «кто-то может не вернуться».
- Если много тегов скрыто (`???`), прогноз **размыт**: «Опасно — Неясно». Разведка и особые действия (тень Санни) снимают неопределённость.
- До запуска прогноз считается по лучшему доступному действию; в окне прибытия у каждого действия свой прогноз.

## 6. Прибытие и выбор действия

Кольцо догорает → звук и вспышка над картой миссии → щелчок → **окно прибытия**:

- **Что увидели** — продолжение описания, часть скрытых тегов раскрывается («Под брезентом — кокон. Одна тварь крупнее остальных» → `Ярость`).
- **Варианты действий:**
  - базовые — есть всегда: «Броситься в бой», «Выждать и ударить из укрытия», «Отступить» (миссия не выполнена, но без ран);
  - особые — открывают **теги отряда**:
    - `Тень` → «Послать тень вперёд»: раскрыть всё и получить преимущество на этапе подхода;
    - `Огонь` → «Поджечь повозку с телами»: лишить паразитов носителей;
    - `Холод` / ночь → «Дождаться утреннего мороза»: твари вялые;
    - `Импровизация` → «Обрушить на них обломки».
- У каждого действия — прогноз словами и **кто из отряда действует** (подсветка карт).

## 7. Этапы, бой и отчёт

Действие раскладывается на **1–3 этапа** (например: подход → столкновение → отход). На каждом этапе — скрытый бросок по нынешней формуле (5–95%), в котором участвует самый подходящий герой отряда, его теги и связи. Результат этапа — **успех / частичный / провал** и влияет на следующий этап.

- Этап-бой → **автобой**: экран «Столкновение», отряд сам выбирает приёмы, игрок смотрит (кнопка «промотать»). Раны врага сохраняются, как сейчас.
- **Отчёт** — хроника по этапам короткими строками + итог: награды (карты, осколки, новые миссии/локации/герои), травмы, износ, погибшие, время отдыха каждого героя.
- Сюжетная миссия ★: успех (или частичный успех, если так задано) открывает следующие миссии. Провал — миссию можно повторить; описание и враги помнят прошлую попытку.

## 8. Герои, усталость, смерть

- **Состав.** Глава 1 — Санни и временные спутники по книге (Ауро, Шолар, Шифти). С Академии — много героев; новые приходят наградами миссий.
- **Занятость.** Герой в пути или на миссии недоступен для других отрядов.
- **Усталость — отдых по таймеру:** после миссии герой «Отдыхает» 20–60 с (дольше после тяжёлой миссии или с травмами), в лагере быстрее.
- **Смерть навсегда.** Бросок смерти при травме остаётся. Погибший уходит из состава. Игра окончена, если героев не осталось (в Главе 1 это фактически смерть Санни).
- **Таймеры идут только в игре**: сохраняются и продолжаются при следующем запуске.

## 11. Решения владельца (25.09.2026)

- исход — **по этапам**, частичный успех возможен;
- **несколько отрядов** одновременно;
- темп — **усталость героев** (отдых по таймеру), **без глобального давления** (Натиска нет);
- выбор действия — **после прибытия**, варианты **зависят от отряда**;
- смерть — **навсегда**;
- бой — **автобой с просмотром**;
- размер отряда — **задаёт миссия**;
- таймеры идут **только в игре**;
- провал сюжетной миссии — **можно повторить**;
- тексты — **черновик пишет Claude, владелец правит**;
- шесть слов прогноза — **подходят** (Безнадёжно · Очень опасно · Опасно · Неясно · Хорошие шансы · Уверенно);
- «Отступить» — миссия не выполнена, **без ран, но отряд устаёт** (отдых как после миссии);
- побочные и случайные миссии появляются **тремя путями**: по сюжету, **после N завершённых миссий** и **по таймеру** у локации;
- **осколки душ** тратятся в **магазинах**: карты усилений и **карты персонажей** (так растёт состав);
- **Академия заканчивается** завершением её сюжетной (финальной) миссии — без срока;
- в автобой **вмешаться нельзя**;
- **маны больше нет**: в миссиях её нет с Ф1 (проверка данных это запрещает), старые механики на мане (Концентрация, Оберег, Прозрение, приёмы за ману, добыча маны) уходят вместе со старым планшетом событий в Ф3;
- **магазин** — отдельная иконка на карте главы (не локация и не миссия); за осколки душ продаёт карты усилений и карты персонажей; **ассортимент обновляется раз в 7 завершённых миссий**.

## 13. Формат данных миссии (Ф1)

Файлы: `data/locations.json` — локации глав, `data/missions/*.json` — миссии. Старые `data/events` пока живут рядом, миссии их не трогают.

**Локация:** `id`, `name`, `chapter`, `region`, `pos` [x, y] 0..1 на карте главы, `text`, `random` — случайные миссии места: `pool` (id миссий), `every` (раз в N секунд), `after_missions` (после N завершённых миссий).

**Миссия:**

| Поле | Что это |
|---|---|
| `id`, `from_event`, `lore` | код миссии (MS…), из какого события старой схемы, описание «По книге» |
| `location`, `type` | где (id локации); story · side · random |
| `title`, `briefing` | название; «Что происходит» |
| `rumors` | «Что говорят»: `[{text, tag}]`, намёк в тексте в [квадратных скобках] — он подсвечивается и указывает на тег |
| `threat`, `duration`, `rest` | угроза 1–5; время в пути 5–15 с; базовый отдых отряда, с |
| `squad` | `{min, max}` — мест в отряде (1–5) |
| `enemies`, `field` | противники и поле боя (как в бою сейчас) |
| `known_tags`, `hidden_tags` | теги врага и места: видны сразу / раскрываются по прибытии или разведчиком |
| `context`, `trauma_pool` | теги проверки (бонусы карт «в бою», «в скрытности»…); пул травм |
| `arrival` | «Что увидели» по прибытии |
| `actions` | варианты действий после прибытия (ниже) |
| `start`, `next`, `unlock` | доступна с начала главы; какие миссии открывает сюжетный успех; условие появления (`after_missions`) |

**Действие:** `id`, `label`, `text`, `requires_any` (боевые теги, хотя бы один должен быть у отряда — так открываются особые действия), `story` (двигает сюжет), `retreat` (отступление), `stages` (1–3), `on_success` / `on_partial` / `on_failure` (команды последствий, как сейчас).

**Этап:** `name`; проверка — `req` {характеристика: число} и `tags` (теги проверки этапа), или бой — `combat` {enemies, field}, или `auto`; тексты `ok` / `partial` / `fail` для отчёта.

## 14. Правила ядра (Ф2, сделано)

Код: `core/rules/mission_flow.gd` (миссии, герои, отряды, часы, действия), `mission_forecast.gd` (прогноз), `mission_resolver.gd` (исход), бой — `CombatSession.create_for_mission` + `auto_play`.

- **Новое прохождение** в режиме миссий: только Санни, открыты миссии главы с `start`; маны нет.
- **Отряд**: герои живые, не на миссии и не отдыхают; число — по `squad` миссии. Пока отряд в пути, миссия «в работе».
- **Часы** идут только в игре (`tick`): прибытие отряда, конец отдыха, случайные миссии локаций по `every` секунд.
- **Этап-проверка**: действует лучший для этапа герой отряда; шанс — прежняя формула, ограничен 5–95%. Бросок ≤ шанса — успех; до шанса +25 — частично; выше — провал. Провал — травма герою, частично — травма с шансом 50% (с броском смерти, как сейчас).
- **Этап-бой**: автобой; ведущий — герой с лучшим шансом, остальные в поддержке; приём с лучшим шансом каждый раунд; раны врага сохраняются до следующей попытки.
- **Итог действия**: успех — без проваленных этапов и в основном «успех»; «с потерями» — провалов не больше трети этапов; иначе провал. В миссии из 1–2 этапов любой проваленный этап — провал миссии.
- **Последствия**: `on_success` / `on_partial` / `on_failure`; сюжетное действие при успехе или «с потерями» открывает `next`; после каждой выполненной миссии — миссии «после N миссий» и случайные «после N» у локаций.
- **Провал**: миссия снова открыта, попытка засчитана. **Отступление**: без ран, миссия открыта, попытка не считается.
- **Отдых**: база миссии (`rest`) + 10 с за каждый проваленный этап + 15 с за каждую травму героя.
- **Смерть навсегда**: погибший уходит; игра окончена, когда живых героев не осталось.
- **Прогноз**: те же шансы этапов и то же правило сложения, перебором всех исходов. Слово — по «успех + ½ частичного». Без разведчика (`Выслеживание`, `Тень`) скрытые теги врага не учитываются, и прогноз размыт диапазоном в 12 пунктов. Риск — вероятность травмы хоть на одном этапе.
- **Проверено тестами**: прогноз совпадает с реальностью в пределах ±15 (300 прогонов на действие), бот проходит пробные миссии в 200 из 200 прохождений.

## 15. Интерфейс (Ф3, сделано)

- «Новая игра» в меню запускает режим миссий (`scenes/missions/mission_game.tscn`); «Продолжить» открывает тот режим, в котором сохранена игра. Прежняя механика доступна кнопкой «Старый режим: события» — пока главы переносятся в миссии (Ф5); **мана и старый планшет живут только там** и уйдут вместе с ним, когда Глава 1 целиком станет миссиями.
- Карта главы: миссии — карты (`MissionMarker`, `CardView` вида `mission`) у своих локаций; героя можно бросить прямо на карту — откроется брифинг с ним в отряде. После «Выступить» над картой — кольцо таймера с секундами («отряд в пути», карта притушена), по прибытии — горящее кольцо с «!». Сверху — глава, осколки душ, отряды в пути. Внизу — герои с состоянием («свободен», «на миссии», «отдыхает N с») и усиления; правый щелчок — планшет карты.
- Окно миссии (`MissionWindow`): брифинг (что происходит, слухи с подсвеченными намёками, угроза, время в пути, противники, известные теги и «???», места отряда — перетаскиванием или щелчком, прогноз словами с риском и пояснением) → «Выступить» → прибытие (что увидели, раскрытые теги, действия с прогнозом каждого, особые — со значком тега) → отчёт (этапы с исходами и текстами, «Смотреть бой», награды, травмы, отдых).
- Просмотр автобоя — экран «Столкновение» в режиме просмотра: отряд выбирает приёмы сам, кнопка «Промотать». Воспроизводится тот же бой, что посчитан (тест `test_combat_replay_matches`).
- Автобой осторожен: «Всё или ничего» — только при шансе раунда от 55%, при шансе ниже 35% — защита, если есть.
- Часы стоят, пока открыт просмотр боя.
- Автоснимки: `Godot --path . --resolution 1920x1080 -- --mshots=<папка>` (`tools/mission_shots.gd`).

## 16. Герои и магазин (Ф4, сделано)

- **Магазин** — `data/shops.json`: `id`, `chapter`, `name`, `text`, `pos` [x, y], `slots` (карт на витрине), `min_characters` (мест, гарантированных персонажам), `refresh_every` (раз в N завершённых миссий), `stock` — `[{card, price?}]`, только персонажи и усиления. Без `price` цена по редкости (`ShopRules.PRICE`: усиление 5/9/16/28, персонаж 8/14/20/35).
- **Витрина** (`core/rules/shop_rules.gd`) — `slots` карт из `stock`, выбор детерминирован (зерно прохождения + номер обновления). Уже купленные карты и погибшие герои не выставляются. Новый номер обновления — после каждых `refresh_every` миссий; иконка пульсирует «новый товар!», пока игрок не заглянет. Состояние — `RunState.shops` (сохраняется).
- **Первый Кошмар**: «Меняла у костра» — 4 карты, минимум 1 персонаж; в ассортименте Шолар и Шифти (по 8 ✧), Ауро (20 ✧) и шесть знаний. На стартовые 10 осколков можно сразу взять одного попутчика — текст и цены на правку владельцу.
- **Герои приходят** из магазина и наградами миссий (`add_card` персонажа в `on_success` и т. п.) — сразу свободны и встают в ряд внизу экрана.
- **Несколько отрядов** одновременно: над каждой картой миссии — своё кольцо; занятый герой в другой отряд не встаёт.
- **Кармашки у всех героев**: усиление перетаскивается на героя внизу экрана или кладётся в планшете героя (правый щелчок, в т. ч. из брифинга — прогноз сразу пересчитывается). Под усилением — чей кармашек. Пока герой на миссии, его кармашек не меняется, и ушедшее с ним усиление не забрать (`MissionFlow.pocket_lock`).
- **Героя можно бросить прямо на карту миссии** — брифинг откроется с ним в отряде.
- **Редактор**: вкладка «Миссии» → раздел «Магазины» (описание, место, витрина, ассортимент и цены; пустая цена — по редкости).
- Тесты: `tests/test_heroes_shop.gd` (витрина, покупка, обновление раз в 7, погибшие не продаются, два отряда сразу, замок кармашка, сохранение).

## 17. Первый Кошмар на миссиях (Ф5, сделано)

Файлы: `data/missions/ch1_nightmare.json` (сюжет), `data/missions/ch1_side.json` (побочная и случайные), `data/locations.json`.

| Место на карте | Миссии |
|---|---|
| Грань сна | MS01 «Заражение Заклинанием» — старт главы |
| Караван рабов | MS02 «Караван рабов»; SM01 «Разговор у костра» (после 2 миссий); RM04 «Знахарь каравана» (случайная, после каждых 3 миссий) |
| Павший караван | MS03 «Личинки Горного Короля», MS04 «Разорванные цепи»; RM01 «Обыск повозки» (случайная, раз в 90 с) |
| Тропа Горного Короля | MS05 «Горный Король» (угроза 5); RM02 «Выводок в расщелине» (случайная, бой) |
| Разрушенная дорога | MS06 «Разрушенная дорога», MS07 «Падение Шифти»; RM03 «Ночной холод» (случайная, раз в 120 с) |
| Ночной привал | MS08 «Запах крови», MS09 «Последние слова Героя» (бой с Ауро) |
| Храм Бога Теней | MS10 «Храм Бога Теней», MS11 «Оценка Заклинания» — конец главы |

**Новые правила данных:**
- Сюжетная миссия продвигает сюжет **любым** удачным действием — действия теперь разные пути к одной цели; ★ отмечает путь по книге. (Раньше несюжетный успех закрывал миссию, а следующая не открывалась — глава застревала.)
- `requires_hero` у действия — нужен кто-то из этих героев в отряде («Положиться на Ауро», «Довериться Шолару»).
- `requires_heroes` у миссии — без этих героев отряд не уйдёт (MS10, MS11 — только с Санни). **Если такой герой гибнет до своей сюжетной миссии — прохождение окончено** (в Главе 1 это Санни).
- `exclude_heroes` — кто не может идти (MS07 — Шифти: беда случилась с ним; MS08–MS09 — Ауро).
- `on_complete` — последствия самой миссии после любого удачного действия (MS08: Ауро уходит и становится врагом; MS11: итоги Заклинания, травмы Санни сняты, спутники из Кошмара остаются в Кошмаре).
- `end_chapter` — миссия завершает главу: экран «Первый Кошмар пройден».
- Ушедший по сюжету герой покидает отряд в пути; его кармашек пустеет.
- Случайные миссии появляются только в местах, куда уже привёл сюжет.

**Попутчики**: Шолар и Шифти приходят с MS04 «Освободить остальных», Ауро — с «Помочь Ауро»; всех троих можно и купить у Менялы. Шифти может погибнуть в MS07 (или спастись), Ауро уходит после MS08. Оценка Заклинания уводит всех временных спутников — **на решение владельца** (см. §12).

**Баланс по боту** (120 прохождений, бот покупает попутчиков и берёт действие с лучшим прогнозом): Первый Кошмар проходится в ~97%, ~17 попыток и ~4 минуты игрового времени. Сложнее всего MS09 (≈79%), RM02 (≈76%), MS06 (≈88%). Пока легко — доводка в Ф6.
