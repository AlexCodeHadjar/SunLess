# 17 — Дни без тупиков: переходы, вода, планировщик

Решения владельца 29.09.2026. Подробный разбор для чтения — Word «Забытый Берег — алгоритм дня, воды, мест и событий.docx» (docs/). Здесь — справка для кода.

## §1. Решения

- Затопление — одна фаза: шторм 1 день, неделя Берега 7 дней (`days.json → weeks`), сюжетные приливы стоят 1 день (`gen_shore.py → TIDES`).
- Переходы — шаги дня: маршрут по тропам одним щелчком; `steps_free` (3) переходов в день бесплатно, дальше марш-бросок `march_psyche` (−6) всем за переход. Далёкую миссию запускают сразу — отряд идёт сам.
- Всегда есть что делать: утром не меньше `min_options` (2) миссий в досягаемости без марш-броска (иначе местные встречи) + дела лагеря.

## §2. Карта-граф и туман (`travel_rules.gd`, `map_rules.gd`)

- Узлы — места карты-плана и лавки; рёбра — `MapRules.links`. Лавка — проход: встать лагерем нельзя (`can_stop`).
- Проходимо: место на карте и не под водой. `route()` — поиск в ширину, соседи по алфавиту (маршрут стабилен); `dry_only=false` — путь через воду (для тумана и «отрезано водой»).
- `why_not()` — причина: на миссии / лавка / под водой / отрезано водой / нет тропы.
- `travel()` — шаги `flags.steps`, марш сверх `steps_free`, места пути → `flags.visited`, лагерь переезжает. `MissionFlow.launch` сам вызывает `travel` для не-натиска.
- Туман `MapRules.known()`: посещённые + разведанные (`flags.scouted`) + лагерь + места сюжета → они и их соседи; служба `view` — ещё кольцо; путь к каждой открытой миссии (через воду тоже).
- Проверка данных `ContentValidator.dry_spine_errors`: все постоянные места связаны; высоты + лавки связаны без low/mid. Для этого добавлена тропа Расщелина — Высота.

## §3. Вода

Без изменений в алгоритме (docs/16 §11.1, §12), кроме длительности: `flood` = 1 день. Сюжетная вода во время недельной продлевает её, а не прибавляет.

## §4. Планировщик (`day_planner.gd`)

- `options()` → `{today, march, cut}` по открытым миссиям главы (натиск — всегда today).
- `ensure()` — утром (`DayRules.end_day`, последний шаг) и в начале главы (`MissionFlow.open_chapter`): недостаёт до `min_options` — кандидаты: можно встать лагерем, сухо, нет открытой миссии, маршрут ≤ `steps_free`; ближние первыми → `spawn_local()` (`random.local`, затем `random.pool`, колода разрешает). Событие `planner`.

## §5. Местные встречи

`tools/shore_local.py` → LS01–LS17, по одной на место (`locations.random.local`), шаблоны по высоте, угроза 1–2, 2–4 осколка, срок 1–2 дня, поле `local: true`.

## §6. Дела лагеря

`days.json → tasks`: scout (открыть места в 2 переходах + встреча), forage (осколки, после отлива больше), watch (ночное нападение × `danger_mult`). Раз в день каждое (`flags.tasks_done`), исполнитель тратит выход (усталость). Интерфейс — кнопки под панелью дня, выбор героя.

## §7. Интерфейс и обучение

Окно перехода по щелчку на место, кнопки «идти» у соседей, метки «N перехода · МАРШ» / «ЗА ВОДОЙ», путь в брифинге и «Идти и выступить», строка «Сегодня: …». Подсказки T40–T48 (`data/tutorial.json`), устаревшие T03/T08/T25/T26/T30 переписаны.

## §8. Проверка

`tests/test_travel.gd`: сухой хребет в худший прилив, маршрут и шаги, объяснение воды, путь к миссиям виден, далёкий запуск, утренняя гарантия, дела лагеря, 40 прогонов бота (бот видит только открытое): пустых утр 0, скрытых миссий 0, сюжет ждёт воду ≤ 1 дня подряд.
