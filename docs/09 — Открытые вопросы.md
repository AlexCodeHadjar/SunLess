## Журнал решений

### Последствия провала

| Вопрос | Решение |
|---|---|
| Когда персонаж погибает? | При каждой новой травме, если травм стало 3 и больше: 15% при трёх, +20% за каждую следующую (35, 55, 75, 95, затем 100%). |
| Может ли погибнуть Санни? | Да — это конец прохождения. |
| Как выбирается травма? | Случайно из травм, которых у персонажа ещё нет. |
| Когда ломается усиление? | Шанс 1% при первом использовании, +5% после каждого. |
| Что означает «сломано»? | Карта уничтожена. |
| Что не изнашивается? | Способности, карты-знания, Эхо. |
| Как чинить? | Легендарный кузнец за монеты сбрасывает износ до 1%. Уничтоженное не восстанавливается. |

### Карты-инициаторы

| Вопрос | Решение |
|---|---|
| Одноразовые ли? | Да. |
| Возвращаются ли? | Нет. |
| Где использовать? | Везде. |
| Что создают? | Всегда одно конкретное событие. |
| Создают ли случайные события? | Нет. |

### Появление событий

| Вопрос | Решение |
|---|---|
| Нужны ли инициаторы сюжетным событиям? | Нет. |
| Когда появляется следующее сюжетное? | Со случайной задержкой 0–2 недели после успеха; если на карте пусто — сразу. |
| Случайные события | 30% в неделю из пула региона. |

### Сюжет и карты

| Вопрос | Решение |
|---|---|
| Какой вариант продвигает сюжет? | Только сюжетный. Остальные дают награду; событие остаётся. |
| Стадии Санни | Раб 3/5/6 → Спящий 4/7/8 → Санлес 5/8/10. |
| Способности | Отдельно от усилений, слотов не занимают. |
| Видимость последствий | Значками; подробности раскрывают способности, знания и Прозрение. |
| Серебряный Колокольчик | По книге выдан в гл. 8 «Дитя Теней» (E06); использован в гл. 13–14 (E09–E10). Прежняя запись о выдаче в E09 исправлена после сверки. |
| HP | Нет; все «здоровье» заменены травмами. |
| Два героя в одном событии (E112 и др.) | Один исполнитель, второй — условие «в коллекции». |
