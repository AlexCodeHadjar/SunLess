# 2. Бой «Столкновение»: правила

## 2.1. Когда начинается бой

`[Предложение]` Бой — это **особый тип варианта события** (`check: combat`). У боевого события один-два варианта ведут в «Столкновение», остальные остаются обычными проверками (обойти, отвлечь, сбежать). Так бой не заменяет существующую систему, а становится её самой яркой частью.

Примеры: E03 «Драться цепью» → бой с Личинками; E05 «Сдерживать напрямую» → бой с Горным Королём (почти безнадёжный — и игрок это видит заранее); охоты в Мрачном городе — целиком боевые события.

## 2.2. Участники

| Участник | Что это | Откуда теги |
|---|---|---|
| **Герой** | один персонаж (правило «один исполнитель» сохраняется) | ранг, аспект, особенности, способности, до 3 усилений, травмы-состояния |
| **Противник(и)** | 1–5 карт существ | ранг, класс, особенности, анатомия, материал, поведение |
| **Поле боя** | карта места | 1–3 тега местности / погоды / времени суток |
| **Карта раунда** | открывается в начале каждого раунда | 1 тег + особое условие раунда |
| **Спутники** `[Предложение]` | не сражаются, но могут дать 1 тег «Поддержка» | см. вопрос 9.6 |

## 2.3. Порядок боя

```text
ПОДГОТОВКА   герой + ≤3 усиления → поле боя раскрыто → видна предварительная сила обеих сторон
РАУНД 1      открывается карта раунда → пересчёт → решение игрока (приём) → бросок раунда
РАУНД 2      то же; победитель прошлого раунда получает «Натиск»
(РАУНД 3)    для элиты и боссов
ИТОГ         победа в большинстве раундов = успех события; поражение = провал (травмы)
```

## 2.4. Длина боя

| Тип противника | Раундов | Победа | `[Предложение]` при ничьей 1:1 |
|---|---:|---|---|
| Обычный | 2 | выиграть оба **или** 1:1 и выиграть «раунд истощения» | раунд истощения: без карты раунда, у обеих сторон −20% |
| Элита | 3 | 2 из 3 | — |
| Босс | 3 + фазы | 2 из 3; после каждого раунда босс меняет 1 особенность («фаза») | — |
| Стая / орда | 2–3 | как элита; каждая проигранная стаей схватка убирает одну карту противника | — |

## 2.5. Цена раунда (без HP)

`[Предложение]` Каждый **проигранный героем раунд** даёт 1 случайную травму из пула, подходящего противнику (когти → физическая, очарование → ментальная). Это та же система травм и та же проверка смерти, что уже есть в игре. Выигранный раунд даёт «Натиск» (+10% силы в следующем раунде).

Итог боя:
- **Победа** — успех события, добыча (осколки души, шанс Эха, Воспоминания по данным противника).
- **Поражение** — провал события; событие остаётся на карте, как обычно.
- **Отступление** (приём, см. §4) — бой прекращается без новых травм, событие остаётся, противник может получить «Настороженность» (+10% при следующей встрече).

## 3.2. Формула `[Предложение по вашей схеме]`

```text
Шаг 0. База:           Г = 100, В = 100
Шаг 1. Ранг:           Δ = ранг_врага − ранг_героя
                       если Δ > 0: В ×= 1.6^Δ;   если Δ < 0: Г ×= 1.6^|Δ|
Шаг 2. Класс:          В ×= множитель класса (для стаи — средний)
Шаг 3. Аспект и особенности (уместные в этом бою):
                       Г ×= (1 + Σ бонусов тегов героя, но не больше +100%)
                       В ×= (1 + Σ бонусов тегов врага, но не больше +100%)
Шаг 4. Симбиозы (комбинации внутри одной стороны):
                       сторона ×= (1 + Σ симбиозов, не больше +80%)
Шаг 5. Конфликты (тег одной стороны обесценивает тег другой):
                       обесцениваемый тег теряет часть бонуса ИЛИ сторона получает штраф
                       сторона ×= (1 − Σ конфликтов, не больше −60%)
Шаг 6. Поле боя:       каждая сторона ×= (1 + Σ влияний поля; от −40% до +40%)
Шаг 7. Карта раунда:   то же, для тега текущего раунда
Шаг 8. Состояния:      травмы героя −5% за каждую (физ./мент. по типу раунда); «Натиск» +10%
Шаг 9. Характеристика раунда: карта раунда называет Силу, Волю или Хитрость;
                       герой ×= 1 + 0.04 × (значение − 5)     [связь со старой системой]

Шанс героя выиграть раунд = Г / (Г + В)       → бросок 1..100
```

Ограничения шагов («не больше +100%» и т.п.) нужны, чтобы комбинации не разгоняли силу до бесконечности и бой не решался одним удачным набором. Значения — стартовые, баланс в Фазе 1.

## 3.3. Пример: Санни-раб против Личинки Горного Короля (E03)

| Шаг | Санни | Личинка | Комментарий |
|---|---:|---:|---|
| База | 100 | 100 | |
| Ранг (Спящий vs Спящий, Δ 0) | 100 | 100 | |
| Класс (Зверь ×1.0) | 100 | 100 | |
| Теги: Санни — `Хладнокровие` (+10%), `Импровизация` (+15% с U01); Личинка — `Паразит` (+10%), `Шипы` (+15%), `Ярость` (+10%) | 125 | 135 | |
| Симбиоз Личинки: `Паразит` + `Мёртвое тело` (поле «Павший караван») → «Оживление трупов» +20% | 125 | 162 | неприятный сюрприз |
| Конфликт: `Цепь` (U01) против `Мягкое тело` → Личинка −15% | 125 | 138 | цепь хлещет по мягкой плоти |
| Поле «Горный путь»: `Холод` — Личинка `Хладнокровная тварь` −10% | 125 | 124 | |
| Карта раунда 1 «Кровь на снегу»: `Запах крови` → `Ярость` Личинки +15% | 125 | 143 | |
| Характеристика раунда — Сила (3): 1 + 0.04 × (3 − 5) = ×0.92 | 115 | 143 | |
| **Шанс раунда** | **45%** | | игрок видит это *до* решения |

Игрок видит, что шансы плохие, и в приёме раунда выбирает «Использовать окружение»: переключает характеристику раунда на Хитрость (6) — ×1.04 → 130 против 143 → **48%**. Или тратит Колокольчик… Решение принадлежит игроку, а бой объясняет каждую цифру.

## 3.4. Несколько противников

`[Предложение]` Силы складываются, но большая группа получает тег `Стая` (+10% за каждого сверх первого, максимум +40%). Узкие места (`Узкий проход`, `Мост`) конфликтуют со `Стаей` и считают только двух противников. Каждая выигранная героем схватка против стаи убирает самую слабую карту противника.

# 4. Решения игрока внутри боя

`[Предложение]` Без решений в раундах бой превращается в «смотреть на анимацию». После открытия карты раунда игрок выбирает **один приём** из трёх, собранных из его тегов и карт:

| Приём | Откуда | Эффект |
|---|---|---|
| **Сменить хватку** | всегда | заменить 1 усиление на другое из коллекции (пересчёт симбиозов) |
| **Сменить подход** | всегда | переключить характеристику раунда на другую (Сила ↔ Воля ↔ Хитрость) за 3 маны |
| **Приём аспекта** | способность героя | Санни: «Уйти в тень» — удваивает теги `Тень`/`Скрытность` в этом раунде, но не работает при `Свет` на поле. Нефис: «Бессмертное пламя» — +40% и снять физическую травму, цена — `Боль` |
| **Использовать поле** | тег поля + подходящий тег героя | «Обрушить камни», «Столкнуть в пропасть», «Увести в туман» — превращает тег поля в свой симбиоз |
| **Жертва** | Эхо / расходуемое | Эхо принимает проигранный раунд на себя и уничтожается |
| **Отступить** | всегда (кроме боссов) | конец боя без новых травм, событие остаётся |

## 5.2. Анимация и эффекты

| Момент | Что происходит | Эффекты (есть в проекте) |
|---|---|---|
| Вход в бой | экран темнеет, карты выезжают навстречу, поле боя «проявляется» из дыма | чёрный дым, туман |
| Карта раунда | падает сверху и переворачивается; её тег вспыхивает и «летит» к тем тегам, с которыми связан | искры, линии связей |
| Каждый шаг летописи | строки появляются по одной; стрелка на весах сдвигается с каждым множителем | тиканье, серебряная пыль |
| Симбиоз | между двумя тегами одной стороны загорается серебряная линия, теги пульсируют | серебряные искры |
| Конфликт | между тегами разных сторон — багровая молния, «проигравший» тег трескается | багровые искры, треск |
| Бросок раунда | весы качаются, указатель останавливается | бросок кубика, звон / глухой удар |
| Выигранный раунд | карта героя рывком наносит «удар», карта врага отбрасывается, трескается угол | вспышка, дрожь |
| Проигранный раунд | карта героя тускнеет, на неё падает карта травмы | тёмный дым, звук травмы |
| Победа | карты врагов сгорают в пепел (как карта события) | шейдер распада |
| Открытие новой связи | тег раскрывает сетку: новая линия прорисовывается, надпись «Открыта связь» | гравюрный штрих, звон |

## 5.3. Мысли героя в бою

Облачка из текущей системы: перед раундом («Шипы. Значит, не в лоб»), при открытии связи («Мёртвые встают… от трупов подальше»), при низком шансе («Сорок пять процентов. Хуже, чем хотелось бы»).

## 6.2. Гиперссылка

- Любой тег в тексте, на карте, в летописи боя — **подчёркнутое слово** с маленькой иконкой категории.
- **Наведение** (0.3 с) — карточка тега: название, категория, описание, текущий вклад в этом бою («+15% Санни»), откуда тег («аспект Санни», «Импровизированное оружие»).
- **Ниже в карточке** — «Известные связи»: список открытых симбиозов и конфликтов, у закрытых — `???`.
- **Удерживание Shift** — полупрозрачная сетка связей поверх экрана (см. 6.3).
- **Клик** — Кодекс, раздел «Связи», с этим тегом в центре.

## 6.3. Сетка связей

```text
                    ??? ·
                        ·
      Засада ─────── ТЕНЬ ═══════ Тьма
     (симбиоз)        ║  ╲        (симбиоз «Дитя ночи»)
                      ║   ╲ ???
                   ▓▓▓▓▓▓
                   Свет
                (конфликт «Свет рассеивает тень»)
```

- Узел в центре — тег; вокруг — связанные теги по кругу.
- **Серебряная линия** — симбиоз, **багровая пунктирная** — конфликт; толщина = сила эффекта.
- Неоткрытые связи: тусклый узел `???` и еле заметная линия — игрок знает, *что связь существует*, но не знает с чем.
- Сетка полупрозрачная (фон 60% прозрачности), лежит поверх текущего экрана и не мешает клику.

## 6.4. Открытие связей

- Связь открывается **при первом срабатывании** в бою (или в проверке события, если там тоже используются теги).
- В момент открытия: пауза 0.6 с, линия прорисовывается гравюрным штрихом, всплывает строка «Открыта связь: Тень + Тьма → „Дитя ночи“ (+30%)».
- Открытые связи хранятся **вне прохождения** (`[Предложение]` — метапрогресс в профиле игрока), см. вопрос 9.8.
- Карты-знания и способности-разведчики (Контроль Теней, Видение Касси) могут **открыть связь заранее** — продолжение текущей механики раскрытия.

# 8. Живая кампания вместо туннеля

## 8.1. Проблема

Сейчас кампания — цепочка E01 → E112: игрок выбирает *как*, но никогда не выбирает *что* и *когда*. Недели ничего не значат, кроме счётчика.

## 8.2. Предложение: «Хроника с якорями» `[Предложение]`

| Элемент | Как работает |
|---|---|
| **Главы-регионы** | Кампания делится на главы (Первый Кошмар, Академия, Берег, Город…). Глава — карта с сетью **мест** (узлов), а не одна линия |
| **Якоря** | Ключевые книжные моменты (Горный Король, храм, Древо Души, Гунлауг…) — обязательные узлы. Их **порядок внутри главы частично свободный**; финальный якорь закрывает главу |
| **Нити** | Побочные сюжетные линии из 2–5 событий (история Шолара, логово Матриарха, долги Айко). Нити можно брать, бросать, потерять. Некоторые нити взаимоисключающие |
| **Перемещение** | Герой стоит в одном узле; переход в соседний — 1 неделя. События живут в узлах. Туман войны: узлы раскрываются разведкой (`Контроль теней`, `Выслеживание`) |
| **Натиск Кошмара** | Шкала давления 0–10: растёт каждую неделю, падает от побед и отдыха. Пороги: 3 — охотники выходят на след (бои), 6 — погода портится (теги поля), 9 — катастрофа главы. Даёт неделям смысл без жёстких дедлайнов |
| **Бродячие угрозы** | Карты монстров, которые **ходят по карте** к герою (по одному узлу в неделю). Можно избегать, устраивать засаду, использовать приманку |
| **Охоты** | Добровольные бои за осколки души, Эхо, Воспоминания. Основной источник силы между якорями |
| **Лагерь** | Узел-хаб: лечение, ремонт, разговоры со спутниками, доверие |
| **Доверие спутников** | Шкала отношений: решения (спасти Шифти, обокрасть его) меняют доверие → спутник помогает или уходит |
| **Отклонение от канона** | Скрытая шкала: чем дальше решения от книги, тем больше альтернативных сцен (не альтернативный сюжет — альтернативный *путь* к тем же якорям) |
| **Эхо решений** | Флаги прошлых глав всплывают позже: спасённый в Кошмаре, пощажённый враг, проданное Воспоминание |

## 8.3. Как это выглядит на карте

```text
          [Храм]◆ (якорь, закрыт)
             │
   [Обрыв]───[Перевал]───[Пещера ?]
      │          │
 [Лагерь]⌂──[Караван]◆──[Лес ?]
      │                     │
 [Руины]──────────────[Логово 🜂]  ← бродячая угроза движется к герою
```

`◆` якорь · `⌂` лагерь · `?` неразведанный узел · `🜂` угроза. Карточки событий стоят в узлах, как сейчас стоят на карте.

## 8.4. Что это даёт

- Настоящий выбор маршрута и приоритетов: сначала якорь или сначала охота ради Эха?
- Бой становится стратегическим ресурсом: сила добывается в охотах, а не только в сюжете.
- Недели значимы через Натиск и бродячие угрозы.
- Канон сохраняется через якоря; уникальность прохождения — через нити, спутников и эхо решений.

# 9. Вопросы к вам

3. **Нижний и верхний предел шанса раунда** (например, 5–95%) — нужен? Сейчас в проверках искусственного минимума нет.
4. **Цена проигранного раунда** — 1 случайная травма (как я предложил)? Или только цена всего боя?
5. **Решения в раундах** — приёмы из §4 подходят? Или вы хотите, чтобы игрок выкладывал карты в каждом раунде?
6. **Спутники в бою** — строго один боец (как в событиях) или спутники могут стоять «в поддержке» и добавлять теги?
7. **Характеристики Сила/Воля/Хитрость** — связывать с боем через «характеристику раунда» (мой §3.2, шаг 9) или бой живёт только на тегах?
8. **Открытые связи** — навсегда для профиля игрока (метапрогресс между прохождениями) или только в рамках прохождения?
9. **Сетка связей** — показывать при наведении сразу или по удержанию клавиши (Shift), чтобы не мешать?
10. **Добыча** — Эхо с шансом после победы над существом, как в книге? Осколки души как ресурс?
11. **Раны противника между боями** — если игрок отступил, враг остаётся ослабленным (или наоборот настороженным)?
12. **Коэффициенты рангов** (×1.6 за шаг ранга и классы ×1.0…×2.5) — такой порядок сил устраивает? Против Тирана Санни-раб почти не имеет шанса — по книге так и есть.
