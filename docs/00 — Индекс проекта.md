## Формула игры

**Событие на карте → персонаж (+ его способности) → 0–3 усиления → один из 3 вариантов → проверка → последствия → +1 неделя**

## Зафиксированные правила

| Система | Правило |
|---|---|
| Характеристики | Сила, Воля, Хитрость |
| HP | отсутствует; состояние определяется травмами |
| Персонажей в событии | ровно 1 |
| Способности | принадлежат персонажу, слоты не занимают, не изнашиваются |
| Усиления | до 3, без дубликатов; износ: 1% + 5% за использование; сломано = уничтожено |
| Травмы | при провале — случайная из тех, которых нет; при 3+ травмах шанс смерти 15% (+20% за каждую следующую) |
| Смерть Санни | конец прохождения |
| Колода | отсутствует; все карты в нижней панели |
| События | ровно 3 видимых варианта; сюжет продвигает только сюжетный вариант |
| Появление событий | сюжетные — сами, с задержкой 0–2 недели; случайные — 30% в неделю; инициаторы — одно конкретное событие |
| Инициаторы | одноразовые, применяются где угодно |
| Ход | одно событие = 1 неделя |
| Событий на карте | без лимита, без срока |
| Повтор после провала | разрешён |
| Ресурсы | мана и монеты, старт 10 / 10 |
| Ремонт | легендарный кузнец сбрасывает износ за монеты |
