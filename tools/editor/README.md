# Редактор контента SunLess

Внешний инструмент для правки карт, тегов и событий игры. Работает в браузере, изменения по кнопке **«Сохранить»** (или Ctrl+S) записываются прямо в `data/*.json` и `art/cards/` проекта.

## Запуск

Двойной щелчок по **`Редактор SunLess.bat`** в корне проекта — откроется браузер с редактором.
Или из командной строки:

```bash
python tools/editor/server.py            # http://127.0.0.1:8765/
python tools/editor/server.py --port 9000 --no-browser
```

Нужен только Python 3.9+ (без дополнительных пакетов). Сервер слушает лишь `127.0.0.1` и пишет только в `data/` и `art/cards/`.

## Что умеет

**Карточки** — галерея всех карт: персонажи, усиления, способности, травмы, инициаторы, противники, события и «задуманные» карты, у которых пока есть только описание «По книге».
- Планшет карты: крупная картинка, вкладки «Описание», «Сюжет (По книге)», «JSON».
- Картинка: щелчок по ней или перетаскивание файла (png/webp/jpg). Файл сохранится как `art/cards/<ID>.<ext>`, старая картинка карты уйдёт в резервную копию, затем редактор сам запустит импорт в Godot.
- Характеристики (Сила/Воля/Хитрость), стадии персонажа, черты, бонусы с условиями, режимы способностей, штрафы травм, ранг/класс противника.
- Теги: наведите на тег — появится **×** для удаления; зелёный **+** справа — добавить (поиск по категориям, можно создать новый тег).
- Новая карта, копия, смена id (все ссылки переименуются), удаление (с предупреждением о ссылках).

**Теги** — боевые теги по 11 категориям и теги проверок событий.
- Свойства (категория, сила, описание), связи (симбиозы и конфликты), список всех мест, где тег используется.
- Переименование обновляет тег во всех картах, противниках, полях, приёмах и связях. Удаление убирает тег отовсюду и удаляет его симбиозы и конфликты.

**Древо событий** — граф: как события идут друг за другом в зависимости от выбора.
- Линии: далее по сюжету (`next`), создаёт событие при успехе/провале (`spawn_event`), инициаторы, открытие главы, якоря и нити Академии, финал по отсчёту, случайные события региона; по флажкам — «раскрытия» и «изменения боя».
- Тяните от кружка **●** справа у варианта к другому событию — появится выбор типа связи. Щелчок по линии — удалить связь. Узлы можно двигать (расположение хранится в `tools/editor/layout.json`), колесо — масштаб.
- Панель события: тип, регион/место главы, текст, теги, следующее событие, три варианта (проверка, требования, цена, бой, тексты успеха/провала), последствия с формами для каждой команды, условия.

## Сохранение и безопасность

- До нажатия «Сохранить» всё хранится только в браузере; обновление страницы отменяет несохранённые правки.
- Перед записью каждый файл копируется в `tools/editor/backups/<дата_время>/` (хранятся последние 30 копий, в git не попадают).
- Запись бережная: неизменённые объекты остаются байт-в-байт, поэтому `git diff` показывает только реальные правки.
- **«Проверить»** повторяет правила `core/content/content_validator.gd`: *ошибки* (игра покажет их вместо меню) и *предупреждения* (игра не проверяет, но стоит взглянуть). При ошибках сохранение попросит подтверждения.
- Меню **Godot** → «Импортировать картинки» и «Запустить тесты» (путь к Godot: `D:\Godot_v4.7.2-stable_win64_console.exe`, иначе укажите его в `tools/editor/config.json`: `{"godot": "C:\\путь\\Godot.exe"}`).

## Генераторы и правки редактора

`tools/gen_combat_data.py` пересобирает теги, связи, поля и противников из `docs/12`, а `tools/gen_lore.py` — описания «По книге». Чтобы они не затирали работу в редакторе:
- правки боевых тегов и противников редактор записывает в `data/combat/editor_overrides.json` (переименования, удаления, изменённые записи) — генератор применяет их поверх документа;
- изменённые описания «По книге» помечаются `"edited": true` — `gen_lore.py` их не перезаписывает.

Правки симбиозов, конфликтов, полей и карт раунда вне переименования/удаления тегов генератор по-прежнему берёт из `docs/12` — их источник правды остаётся в документе.

## Устройство

| Файл | Что |
|---|---|
| `server.py` | HTTP-сервер: `GET /api/data`, `POST /api/save`, задачи Godot, раздача `art/` и шрифтов |
| `web/core.js` | данные, ссылки на теги и id, проверка, файл правок генератора |
| `web/widgets.js` | чипы тегов, выбор тега, поля ввода, загрузка картинок |
| `web/cards.js`, `tags.js`, `events.js` | три экрана |
| `web/main.js` | вкладки, сохранение, проверка, меню Godot |
