# Редактор контента SunLess

Внешний инструмент для правки карт, тегов, миссий и магазинов игры. Работает в браузере, изменения по кнопке **«Сохранить»** (или Ctrl+S) записываются прямо в `data/*.json` и `art/cards/` проекта.

## Запуск

Двойной щелчок по **`Редактор SunLess.bat`** в корне проекта — откроется браузер с редактором.
Или из командной строки:

```bash
python tools/editor/server.py            # http://127.0.0.1:8765/
python tools/editor/server.py --port 9000 --no-browser
```

Нужен только Python 3.9+ (без дополнительных пакетов). Сервер слушает лишь `127.0.0.1` и пишет только в `data/` и `art/cards/`.

## Что умеет

**Карточки** — галерея всех карт: персонажи, усиления, способности, травмы, противники и «задуманные» карты, у которых пока есть только описание «По книге».
- Планшет карты: крупная картинка, вкладки «Описание», «Сюжет (По книге)», «JSON».
- Картинка: щелчок по ней или перетаскивание файла (png/webp/jpg). Файл сохранится как `art/cards/<ID>.<ext>`, старая картинка карты уйдёт в резервную копию, затем редактор сам запустит импорт в Godot.
- Характеристики (Сила/Воля/Хитрость), стадии персонажа, черты, бонусы с условиями, режимы способностей, штрафы травм, ранг/класс противника.
- Теги: наведите на тег — появится **×** для удаления; зелёный **+** справа — добавить (поиск по категориям, можно создать новый тег).
- Новая карта, копия, смена id (все ссылки переименуются), удаление (с предупреждением о ссылках).
- Галочка **«ещё не добавленные в сюжет»** в каждой категории показывает задуманные карты этой категории (есть только описание «По книге»), они отмечены пунктиром.
- Кнопка **«Карты без картинок (JSON)»** скачивает список карт без картинки: `id`, `название`, `категория`, `в_игре`, плюс счёт по категориям.

**Теги** — боевые теги по 11 категориям и теги проверок миссий.
- Свойства (категория, сила, описание), связи (симбиозы и конфликты), список всех мест, где тег используется.
- Переименование обновляет тег во всех картах, противниках, полях, приёмах и связях. Удаление убирает тег отовсюду и удаляет его симбиозы и конфликты.

**Миссии** — места глав, их миссии и магазины (docs/15).
- Слева: места и миссии под ними, отдельно — магазины. «+ Миссия», «+ Локация», «+ Магазин».
- Миссия — страницы «Описание» (тип, место, что происходит, слухи с намёком в [скобках] и тегом, что увидели по прибытии, «По книге»), «Разведка и отряд» (угроза, время в пути, отдых, места в отряде, обязательные и исключённые герои, противники, поле, известные и скрытые теги), «Действия» (до трёх этапов: проверка, бой или без проверки; теги и герои, открывающие действие; последствия успеха, частичного успеха и провала), «Связи» (старт главы, завершает главу, что открывает, откуда приходит, «после N миссий», последствия любой удачи).
- Справа — как миссию увидит игрок.
- Магазин: описание, место на карте, сколько карт на витрине, сколько мест гарантировано персонажам, раз в сколько миссий обновляется, ассортимент с ценами (пусто — по редкости).
- Край планшета тянется мышью, кнопка «Во всю ширину» раскрывает его почти на весь экран.
- У всех полей при наведении на подпись — описание, что это и на что влияет в игре (словарь в `web/tips.js`).

## Связь с игрой: что обновляется само

У редактора нет своей копии данных — он всегда читает проект: `data/**/*.json`, `art/` и код игры.

**Игра → редактор (автоматически):**
- Новые карты, миссии, места, магазины, теги, картинки в `data/` и `art/` появляются в редакторе сами: он раз в 2–3 секунды проверяет файлы и, если в нём нет несохранённых правок, тихо подгружает свежие данные (всплывает «Подхвачены изменения: усиления +1…»). Если правки есть — жёлтая полоса сверху предлагает загрузить свежие данные.
- Любой новый файл в `data/missions/` — новые миссии на вкладке «Миссии».
- При запуске сервер читает определения из кода игры: типы карт (`Content.card_kind` в `core/content/content.gd`), команды последствий и условия (`content_validator.gd`, поля — из `effect_applier.gd` и `condition_checker.gd`), категории тегов (`scenes/combat/tag_text.gd`). Новое сразу работает с общими формами; список подхваченного — в «Проверить».

**Редактор → игра:** «Сохранить» пишет в `data/` и `art/cards/`; игра читает их при следующем запуске (картинки редактор сам импортирует в Godot).

**Защита:** если файл изменили вне редактора после загрузки (Claude, генератор, вручную), сохранение его не затрёт — редактор предложит загрузить свежую версию или перезаписать осознанно.

Чтобы у нового выглядело красиво (русские названия, подсказки), можно дописать: название команды — `EFFECTS`/`CONDITIONS` в `web/core.js`, название типа карт — `KINDS` там же, подсказку — `web/tips.js`. Это необязательно.

## Сохранение и безопасность

- До нажатия «Сохранить» всё хранится только в браузере; обновление страницы отменяет несохранённые правки.
- Перед записью каждый файл копируется в `tools/editor/backups/<дата_время>/` (хранятся последние 30 копий, в git не попадают).
- Запись бережная: неизменённые объекты остаются байт-в-байт, поэтому `git diff` показывает только реальные правки.
- **«Проверить»** повторяет правила `core/content/content_validator.gd`: *ошибки* (игра покажет их вместо меню) и *предупреждения* (игра не проверяет, но стоит взглянуть). При ошибках сохранение попросит подтверждения.
- Меню **Godot** → «Импортировать картинки» и «Запустить тесты» (путь к Godot: `D:\Godot_v4.7.2-stable_win64_console.exe`, иначе укажите его в `tools/editor/config.json`: `{"godot": "C:\\путь\\Godot.exe"}`).

## Генераторы и правки редактора

`tools/gen_combat_data.py` пересобирает теги, связи, поля и противников из `docs/12`, а `tools/gen_lore.py` — описания «По книге». Чтобы они не затирали работу в редакторе:
- правки боевых тегов и противников редактор записывает в `data/combat/editor_overrides.json` (переименования, удаления, изменённые записи) — генератор применяет их поверх документа;
- изменённые описания «По книге» помечаются `"edited": true` — `gen_lore.py` их не перезаписывает.

Правки симбиозов, конфликтов, полей и карт раунда вне переименования/удаления тегов генератор по-прежнему берёт из `docs/12` — их источник правды остаётся в документе.

## Устройство

| Файл | Что |
|---|---|
| `server.py` | HTTP-сервер: `GET /api/data`, `POST /api/save`, задачи Godot, раздача `art/` и шрифтов |
| `web/core.js` | данные, ссылки на теги и id, проверка, файл правок генератора |
| `web/widgets.js` | чипы тегов, выбор тега, поля ввода, загрузка картинок |
| `web/tips.js` | подсказки при наведении: описания полей |
| `web/cards.js`, `tags.js`, `events.js` | три экрана |
| `web/main.js` | вкладки, сохранение, проверка, меню Godot |
