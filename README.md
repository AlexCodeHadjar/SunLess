# SunLess

Сюжетная карточная игра на Godot по мотивам первых двух томов «Теневого раба» (Guiltythree): «Дитя Теней» и «Мрачный город».

> **Фанатский некоммерческий проект.** Имена, мир и сюжет принадлежат автору первоисточника. Концепт-арт в `art/cards` — авторская интерпретация, созданная генератором изображений, а не официальные иллюстрации.

Каждое событие решается **сборкой**: один персонаж, его способности, до трёх усилений и один из трёх способов действия. Шанс виден заранее, последствия остаются на карточках: травмы вместо HP, износ предметов, находки.

## Версия движка

**Godot 4.7.2 stable** (закреплена на весь этап разработки). Рендерер — Compatibility (OpenGL).

## Запуск

1. Откройте Godot 4.7.2 → Import → выберите `project.godot`.
2. Нажмите ▶ (F5).

Из командной строки:

```bash
Godot_v4.7.2-stable_win64_console.exe --path .
```

## Тесты

```bash
Godot_v4.7.2-stable_win64_console.exe --headless --path . -s res://tests/run_tests.gd
```

Код выхода 0 — все тесты прошли. Набор включает формулу шанса, травмы и смерть, износ, проверку данных, разрешение хода, сохранения и симуляцию 300 прохождений вертикального среза ботом (игра не должна застревать).

## Структура

| Папка | Что внутри |
|---|---|
| `core/` | чистая логика без сцен: состояние (`state/`), правила (`rules/`), загрузка и проверка данных (`content/`) |
| `autoload/` | глобальные сервисы: `ContentDB`, `GameState`, `SaveService`, `SettingsService`, `EventBus` |
| `data/` | контент в JSON: персонажи, усиления, способности, травмы, инициаторы, регионы, события |
| `scenes/` | сцены интерфейса |
| `ui/` | тема, шрифты (OFL) |
| `art/` | иллюстрации карт |
| `tests/` | автотесты и бот-симулятор |
| `docs/` | проектные заметки и GDD (копия папки «Игра»; Godot её не импортирует) |

Правило архитектуры: `core/` не знает о сценах. Интерфейс вызывает API `GameState` и слушает сигналы `EventBus`.

## Как добавить событие

Событие — объект в `data/events/*.json`: ровно три варианта, у сюжетного события ровно один вариант с `"story": true`. Последствия — команды из закрытого списка (`add_card`, `add_temp`, `reveal`, `set_flag`…, см. `core/rules/effect_applier.gd`). При запуске данные проверяет `ContentValidator`; при ошибках вместо игры откроется их список.
